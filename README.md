# Data Agent Learning

An interactive, beginner-friendly learning site for **Auto Ontology**, semantic modeling, Text-to-SQL, MCP, and business agents.

## Online tutorial

**[Open the interactive tutorial](https://fangfengxiang.github.io/data-agent-learning/)**

The single-file `index.html` contains 11 interactive sections:

1. Platform architecture and modules
2. Local deployment and model configuration
3. Database connections
4. Automatic semantic compilation
5. Terms, metrics, SQL attributes, and relationships
6. External model import
7. Rules, governance, and access controls
8. Chat / SQL query workflow
9. MCP + Business Agent + Skills
10. Unanswerable questions and feedback
11. MVP acceptance checklist

> This is an independent educational simulation based on public documentation, **not** the official Auto Ontology UI. Its interactive actions are local demos and do not modify a real installation.

## GitHub Pages

The workflow at `.github/workflows/deploy-pages.yml` deploys on every push to `main`, and supports manual runs.

In repository **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source. Then visit the **Actions** tab to check the deployment.
